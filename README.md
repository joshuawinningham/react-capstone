# Little Lemon Restaurant Website

A modern, responsive website for Little Lemon restaurant built with React. This project showcases a beautiful and functional restaurant website with features including online reservations, menu specials, and customer testimonials.

## Features

- 🍽️ Online reservation system
- 📱 Fully responsive design
- 🎨 Modern and clean UI
- 📋 Special menu items showcase
- 👥 Customer testimonials
- 🏠 Homepage with hero section
- 📞 Call-to-action sections
- 🗺️ Location information

## Technologies Used

- React.js
- CSS3
- JavaScript
- Create React App

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/joshuawinningham/react-capstone.git
```

2. Navigate to the project directory:
```bash
cd react-capstone
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm start
```

The application will open in your default browser at `http://localhost:3000`.

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm test` - Launches the test runner
- `npm run build` - Builds the app for production
- `npm run eject` - Ejects from Create React App
